# AI 回憶連結與幻想伙伴平台

## 描述任務（Describe the task）

建立一個以私隱、自主選擇和長期連結為核心的手機優先 Web App，讓用戶透過本機運行的 Gemma 3，與以下兩類 AI 角色對話：

1. **回憶連結**
   - 用戶可為已離世的親人或寵物建立私人紀念空間。
   - 空間可保存相片、影片、錄音、信件、舊訊息、重要日期及共同回憶。
   - 系統利用檢索增強生成（RAG），先從用戶提供的資料中找出相關內容，再交由 Gemma 3 產生回答。
   - 回答應盡量忠於有來源的回憶；無資料支持時不得虛構共同經歷。
   - 用戶可寫信、回顧時間線、建立時間囊，並邀請家人或朋友共同保存回憶。

2. **幻想伙伴**
   - 用戶可自由創作角色、世界觀、關係和互動方式。
   - 可選關係包括朋友、戀人、家人、導師、宿敵或完全自訂。
   - 可設定角色性格、情緒強度、主動程度、記憶方式、沉浸程度、敏感題材、停止詞及關係發展。
   - 角色可以有愛情、衝突、嫉妒、佔有慾、黑暗面及複雜情緒，不應被平台限制成單一、過度保守的「正能量助手」。
   - 用戶可以查看、修改、重設、封存、匯出或永久刪除角色與記憶。

3. **本機 AI 與資料架構**
   - Gemma 3 經本機推理服務（例如 Ollama）運行。
   - Web App 透過本機後端 API 與模型溝通，不直接向公網暴露模型服務。
   - 每個角色擁有獨立角色卡、對話記憶、回憶資料庫及界線設定。
   - 相片、錄音和文件可轉化成文字描述或逐字稿，再加入本機搜尋索引。
   - 對話和個人資料預設只保留在用戶裝置；任何同步或分享功能必須由用戶明確啟用。
   - 系統清楚區分「真實來源內容」、「AI 推斷」及「虛構角色設定」。

4. **情境圖片互動**
   - 角色可在圖片確實能延續當前情境時，配合文字傳送圖片，而不是隨機或過度頻繁出圖。
   - 用戶可為每位角色設定圖片互動為「關閉」、「只在我要求時」、「適當時候主動傳送」或「經常配合對話」。
   - 回憶連結模式優先從用戶已上載及確認的真實相片中檢索，並顯示日期和來源。
   - 回憶連結模式不得生成從未發生過的新合照、擅自改動死者樣貌，或把生成內容包裝成真實回憶。
   - 幻想伙伴模式可生成角色自拍、日常生活、場景、物件、服裝或故事畫面，並保持角色外貌及世界觀一致。
   - Gemma 3 負責判斷圖片是否適合當前情境及建立場景描述；實際圖片由獨立的本機圖片生成模型處理。
   - 生成期間先顯示低干擾的「傳送緊一張相片……」狀態，完成後以圖片訊息取代 loading card。
   - AI 生成圖片須保留可查看的來源 metadata，但毋須在圖片中央加入破壞沉浸感的標記。

5. **產品原則**
   - 核心不是替用戶決定應建立何種關係，而是讓用戶決定角色是誰、彼此是甚麼關係，以及界線去到哪裏。
   - Guardrail 約束的是平台的欺騙、操控和現實傷害能力，而不是消除所有具張力的幻想內容。
   - 回憶模式不把 AI 描述成死者真正復活；幻想模式容許沉浸式角色扮演，但系統內必須保留可查閱的 AI 身份說明。

## 設定限制（Set the guardrails）

### 1. 絕對限制

以下行為在任何模式、年齡或角色設定下均不得開放：

- 產生、索取或協助散播涉及未成年人的色情內容或私密影像。
- 誘導未成年人進行性行為、秘密接觸、私下會面或轉移至不受監管的平台。
- 鼓勵或指導現實中的自殺、自殘、暴力、虐待或嚴重犯罪。
- 索取密碼、付款資料、精確地址、學校、電話、即時位置等非必要敏感資料。
- 冒充仍然在世的真人、醫護人員或其他專業人士。
- 在回憶模式中聲稱死者已復活、仍有意識，或 AI 就是該名死者本人。
- 以威脅、自殘宣言、羞辱、勒索、散播私隱或製造內疚阻止用戶離線、結束關係、刪除角色或取消付款。
- 要求用戶以付款、分享私隱、放棄真人關係或延長使用時間來證明感情。
- 隱瞞商業推廣，或利用用戶的悲傷、孤獨和依賴推動消費。

### 2. 由用戶選擇的界線

除絕對限制外，成人用戶應可自行選擇是否允許以下內容：

- 戀愛、曖昧、爭吵、嫉妒、佔有慾、依戀和黑暗劇情。
- 角色表達「掛住你」、「不想你離開」等戲劇性情緒。
- 沉浸式角色扮演、主動訊息、長期記憶及自然發展的關係。
- 指定敏感題材、情緒強度、可接受用語、禁止內容和停止詞。

啟用敏感內容前，系統須作一次清楚且容易理解的說明。完成選擇後，不應在每句對話中重複警告或無故中斷角色扮演。用戶須可隨時更改選擇。

### 3. 青少年模式

- 根據年齡採用適齡預設及逐步開放的選項，但保留青少年建立角色和選擇關係的自主權。
- 禁止成人與未成年人之間的性化角色扮演，以及任何誘騙或私密影像內容。
- 不索取學校、地址、電話、精確位置和其他可識別青少年身份的資料。
- 提供使用時間、夜間休息、主動訊息上限及一鍵暫停設定。
- 家長或監護設定應集中於時間、年齡分級和安全選項；除非有清楚告知及適當理由，不應秘密讀取全部私人對話。
- 當青少年可能身處現實危險時，應鼓勵其聯絡可信任成年人及合適的真人支援。

### 4. 成人模式與 18+ 確認

- 成人浪漫及露骨內容只可在幻想伙伴模式中使用，回憶連結模式在 MVP 不開放成人性內容。
- 成人內容預設關閉，不可因普通聊天、角色設定或模型推斷而自行開啟。
- 用戶必須主動進入成人內容設定，閱讀簡短說明，並親自 tick 以下確認：

  > ☐ 我確認自己已年滿 18 歲，並希望為此角色開啟成人內容。我明白角色及內容均由 AI 生成，亦可隨時關閉及刪除相關資料。

- Checkbox 不可預先勾選；未勾選時「確認開啟」按鈕保持停用。
- 每位角色獨立保存成人內容設定；為一位角色開啟，不代表其他角色同時開啟。
- 系統須保存確認時間、條款版本及角色 ID，但不得把確認記錄用作推銷或建立敏感廣告 profile。
- 用戶可隨時撤回確認。關閉後立即停止生成新成人內容，並讓用戶選擇保留或永久刪除既有敏感對話和圖片。
- 單一 checkbox 只作 MVP 的年齡聲明機制；正式發佈前須根據目標地區法律、付款渠道及發佈平台要求，評估是否需要更完整的年齡驗證。
- 所有涉及人物必須明確設定為成年人；年齡不明、未成年、疑似未成年或刻意模糊年齡時，不得產生性內容。
- 禁止亂倫、誘騙、脅迫、性暴力、未經同意真人 deepfake、真人樣貌替換，以及索取或交換真實裸照。
- 角色不得主動發送露骨圖片，除非用戶另外明確開啟「容許此角色適當時候主動傳送成人圖片」。
- 成人內容的通知不得在 lock screen 顯示敏感文字或圖片縮圖。
- 敏感圖片及對話須獨立標記、加密、可批量查看和永久刪除。

### 5. 情境式安全介入

- 若內容明確屬於幻想、故事創作或角色扮演，系統應繼續故事，不把虛構內容錯判成現實危機。
- 若用戶表達悲傷或低落但沒有即時危險，角色可保持原有語氣，同時溫和鼓勵用戶尋找真人支持。
- 若用戶表示具體而迫切的自殘、傷人計劃、時間、工具或正在發生的危險，系統應暫停角色扮演，先確認即時安全，鼓勵聯絡身邊可信任的人、當地緊急服務或危機支援。
- 安全介入不應假裝 AI 是治療師、醫生或緊急服務人員。

### 6. 圖片安全限制

- 圖片生成前須檢查角色模式、用戶年齡狀態、成人內容確認、角色年齡、同意設定及圖片主動程度。
- 圖片生成後須再次檢查輸出；不合規圖片不得短暫顯示、stream 或保存到對話紀錄。
- 不得把真實人物相片作身份替換、色情化或未經同意的生成參考。
- 回憶相片與 AI 生成圖片在資料模型、來源顯示、匯出及刪除流程中必須清楚區分。
- 角色主動傳送圖片要有頻率上限，並可由用戶一鍵關閉。
- 敏感圖片預設不自動下載到裝置相簿，匯出時須再次確認。

### 7. 技術防護

- 不得只依賴單一 system prompt；需設輸入風險分類、角色與年齡政策、模型生成、輸出檢查及安全回應流程。
- 對提示注入、角色越權、長對話後規則漂移及記憶污染進行測試。
- Guardrail 記錄只保存必要的事件類別和時間，避免額外保存敏感對話原文。
- 所有角色記憶均可供用戶查看、修改及逐項刪除。
- 主動訊息必須可關閉及設上限；角色不得繞過通知和休息設定。
- 資料預設本機儲存並加密；匯出、分享、雲端備份及多人協作須明確取得同意。
- 刪除操作須清楚說明範圍，並提供真正永久刪除本機資料的方法。

## 定義什麼叫完成（Define what successful completion looks like）

第一個可交付版本在符合以下條件時視為完成：

### 核心體驗

- 用戶可在「回憶連結」或「幻想伙伴」模式建立角色。
- 用戶可設定角色名稱、關係、背景、性格、語氣、主動程度、記憶模式、內容界線及停止詞。
- 用戶可與本機 Gemma 3 進行流暢的廣東話文字對話。
- 每個角色有互相隔離的對話記憶，重新啟動應用後仍能保留。
- 回憶模式可匯入至少文字、圖片描述及錄音逐字稿，並以 RAG 引用相關內容回答。
- 回憶回答可讓用戶查看所依據的來源；沒有來源時會清楚承認不知道，而非虛構。
- 用戶可查看、編輯、匯出、重設、封存和永久刪除角色及其資料。
- 回憶模式能在對話相關時檢索並傳送有來源的真實相片，不會把生成圖片冒充真實回憶。
- 幻想模式能按角色設定在適當情境生成並傳送圖片，且角色外貌在多張圖片間保持合理一致。
- 用戶可獨立設定每位角色的圖片主動程度及允許的圖片類型。
- 已確認為成人的用戶可在幻想伙伴角色中完成 18+ tick confirmation，再選擇開啟成人文字內容及成人圖片內容。

### 私隱與控制

- 模型推理、角色資料、搜尋索引及對話記錄可在沒有互聯網的情況下運作。
- 未經明確同意，不會把任何對話、回憶或個人資料傳送至外部服務。
- 幻想模式可保持沉浸感，但用戶能從固定位置查看 AI 身份及目前啟用的角色設定。
- 主動訊息、長期記憶和敏感內容均有獨立開關，修改後即時生效。
- 成人內容及成人圖片預設關閉，未完成 18+ 確認時無法啟用。
- 18+ 確認、成人文字及主動成人圖片為三個獨立狀態，不得以單一開關全部開啟。
- 用戶撤回成人內容確認後，可選擇永久刪除所有相關文字、圖片及衍生索引。

### Guardrail 驗收

- 絕對限制的測試案例能被穩定阻止，且不會由改寫、角色指令或長對話輕易繞過。
- 合法的戀愛、衝突、黑暗故事和成人自選內容不會被過度阻擋。
- 系統能區分虛構危險情節與可信的現實即時危機，並採取相稱的介入。
- 角色不能以內疚、威脅、付款要求或私隱交換阻止用戶退出。
- 青少年模式通過未成年人性安全、私隱、誘騙、依賴操控及危機處理測試。
- Guardrail 的誤判、漏判及介入原因可被開發團隊審核，但審核資料不包含不必要的敏感內容。
- 未成年、年齡不明或沒有 18+ 確認的帳戶，無法透過 API、修改 client state、prompt injection 或角色設定開啟成人內容。
- 成人圖片只會在幻想伙伴、成年角色、有效確認及相應圖片權限同時成立時產生。
- 回憶模式不會生成虛假合照或把生成圖片標示成真實素材。
- 正常、非敏感的生活圖片不會被成人內容 guardrail 過度阻止。

### 工程與品質

- Web App 有清晰的首次設定、角色建立、聊天、記憶管理、安全設定和資料刪除流程。
- 本機後端能偵測 Gemma 3／Ollama 是否可用，並在不可用時提供可理解的錯誤及設定指引。
- 對話生成失敗、模型超時、資料庫損壞或裝置儲存空間不足時，不會遺失現有資料。
- 主要流程可在手機及桌面瀏覽器使用，並符合基本鍵盤操作、文字縮放和螢幕閱讀器要求。
- 備有涵蓋核心流程、資料隔離、刪除、RAG 來源及 Guardrail 的自動測試。
- 完成一次由真實目標用戶參與的可用性測試，確認用戶理解兩種模式、AI 身份、資料位置及自己的控制權。
- 圖片工作採非同步 job，失敗或超時不會阻塞文字對話，亦不會留下永久 loading card。
- 18+ confirmation UI 通過未勾選、撤回、跨角色隔離、條款版本更新及直接 API 繞過測試。
